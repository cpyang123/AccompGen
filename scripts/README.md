# scripts/

Every shell script in the repo lives here. One convention applies to all of them:

**Submit and run from the repository root**, e.g. `sbatch scripts/run_rhythm_data.sh`
or `bash scripts/submit_strat_eval_multilen.sh inv`. The SLURM `--output=slurm_logs/...`
paths are resolved relative to the submission directory, and the training/eval jobs
`cd finetune/`, `cd notebook/`, `cd distillation/` relative to it. Scripts that need the
repo root explicitly derive it as `$(dirname "$0")/..` or fall back to `$SLURM_SUBMIT_DIR`.
The `submit_*.sh` helpers `cd` to the repo root themselves, so they can be called from anywhere.

## Layout

| Path | What |
|---|---|
| `scripts/*.sh` | Hand-written jobs and submit helpers (51 files), grouped below. |
| `scripts/motif_check/` | 952 auto-generated single-notebook eval jobs (`run_motif_check_*.sh`) from the 2026-06 to 2026-08 ablation campaigns. Each executes one `notebook/motif_check_*.ipynb` headlessly with `jupyter nbconvert`. Regenerate with `notebook/make_*.py`; do not edit by hand. |
| `../experiments/scripts/` | Frozen archive copies (76) referenced by `experiments/MANIFEST.md`; byte-identical to the originals at snapshot time. Not used for launching. |

## Hand-written scripts by purpose

**Data builds** (CPU partition; outputs on scratch, small `.jsonl` indices in `data/`)

| Script | Builds |
|---|---|
| `run_preprocess_irishman.sh` | Irishman JSON to ABC, preprocess, append to the shared v1 indices (`IRISH_MAX_TUNES`). |
| `run_multilen_data.sh` | Multi-length (lengths 4-10) Lieder + Irish set + synthetic crops; backs up and clears the v1 indices first. |
| `run_rhythm_data.sh` | Isolated rhythm-format copy of the inv set (melodic + rhythmic motif per length). Env-overridable for smoke runs. |
| `run_build_irish1k.sh`, `run_build_irish50k.sh`, `run_build_irishfull.sh`, `run_build_irishfull_stage4.sh` | Isolated single-length (len 4) sets of different Irish scale, with their own `data/abcfiles_processed_v1_<tag>_*.jsonl`. |
| `run_rebuild_motifs.sh`, `run_refresh_lieder_motifs.sh` | Re-annotate motifs after extractor fixes (full rebuild vs Lieder-only refresh). |
| `run_add_style_preamble.sh` | Adds `%Period/%Composer/%Art Song` lines above `%motif:` in place. |

**Fine-tuning** (GPU; all call `finetune/train-gen.py` with env overrides, checkpoints go to the scratch `weights/` dir)

| Script | Tag it trains |
|---|---|
| `fine_tune.sh` | Generic: defaults from `finetune/config.py`. |
| `fine_tune_multilen_trans.sh` | `multilen4to10_trans_v1_bias4_syn2real5` (I/R/RI-folded motifs). |
| `fine_tune_multilen_inv_full_rtx6000.sh` | `multilen4to10_inv_v1_bias4_syn2real5` (inversion-format, full FT, Blackwell env). |
| `fine_tune_multilen_inv_lora.sh`, `_lora_a5000.sh` | Same data, LoRA r=16 (`_lora16` suffix). |
| `fine_tune_multilen_rhythm_full_rtx6000.sh` | `multilen4to10_rhythm_v1_bias4_syn2real5` (rhythm-format, full FT). |
| `fine_tune_irish{1k,10k,50k,full}*.sh` | Legacy single-length (len 4) runs and ablations (`bias0`, `nosyn`, `4x4`, `cont6`, `styled`). |
| `run_eval_loss_4x4.sh` | Held-out loss of a checkpoint (`finetune/eval_loss.py`). |
| `snapshot_phase1_bias0.sh` | Watcher that copies the end-of-synthetic-phase checkpoint before the real phase overwrites it. |

**Evaluation**

| Script | What |
|---|---|
| `submit_strat_eval_multilen.sh <tag...>` | Current eval loop: 7 lengths x 3 strata + base = 22 jobs per model tag via `run_strat_eval_multilen.sh`. Knobs: `EVAL_BIAS`, `EVAL_PATTERN_EXTRA`, `EVAL_RHYTHM=1`, `EVAL_N`, `EXTRA_SBATCH`. Aggregate with `experiments/make_multilen_strat_results.py`. |
| `run_strat_eval_multilen.sh` | One (model, length, stratum) job; parameters via env (see header). |
| `run_motif_check.sh`, `run_motif_check_version.sh <VER>` | Legacy notebook-based motif checks. |
| `run_motif_analysis_full.sh` | Full-corpus motif distribution notebook. |
| `submit_ablation*.sh`, `submit_both10ep.sh`, `submit_fullcont6.sh`, `submit_irish1k.sh` | Legacy campaign launchers (train + chained `motif_check/` evals). Regenerated by `notebook/make_*.py`. |

**Distillation (experimental, not part of current results)**: `gen_corpus.sh` (teacher corpus array job), `distill.sh` (stage-1 patch-encoder distillation).
